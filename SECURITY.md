# Безопасность

Нашёл уязвимость — **не открывай публичный issue**. Напиши автору в Telegram:
[@sanyakiller111](https://t.me/sanyakiller111), или через
[GitHub Security Advisories](../../security/advisories/new).

Поддерживается только последняя версия из [Releases](../../releases/latest).

## Что важно знать

- Локальный MTProto-прокси слушает только `127.0.0.1`.
- Секрет прокси генерируется на устройстве при первом запуске.
- APK скачивай только со страницы Releases этого репозитория и сверяй SHA-256
  из описания релиза.
