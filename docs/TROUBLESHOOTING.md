# Проблемы и решения

## Общие

**Кнопка не включается / сразу выключается.**
Проверь, что не работает другой VPN (Happ, v2rayNG, AdGuard в режиме VPN,
Private DNS не мешает). Текст ошибки виден под кнопкой.

**«Разрешение на VPN не дано».**
Нажми кнопку ещё раз и подтверди окно Android. Если окно не появляется —
Настройки → Сеть → VPN → убедись, что у другого VPN не включено «Постоянный VPN».

**Пропадает после блокировки экрана.**
Отключи оптимизацию батареи для Fixer (Настройки → Приложения → Fixer →
Батарея → Без ограничений). На Xiaomi/Redmi ещё включи «Автозапуск».

## Roblox

**Иконки и аватарки серые.** Выключи и снова включи Fixer, затем полностью
закрой Roblox (смахни из недавних). Roblox кеширует пустые ответы DNS.

**Ошибка 279 при входе в игру.** Сообщи в [issue](../../../issues/new/choose) —
игровой UDP должен идти напрямую, это баг.

## YouTube

**Видео не грузится.** Провайдеры меняют блокировку. Стратегия byedpi в Fixer
подобрана под конкретную сеть и может не подойти твоей. Открой issue и укажи
провайдера и тип сети (Wi-Fi / мобильный).

**Работает на Wi-Fi, не работает на мобильном.** Известное ограничение: VPN
работает только по IPv4, а стратегия подобрана под домашний Wi-Fi.
В планах — выбор стратегии ([ROADMAP](../ROADMAP.md)).

## Telegram

**«Подключение…» и ничего не грузится.**
1. Fixer включён и переключатель Telegram активен?
2. В Telegram выключено «Автопереключение прокси»?
3. Если всё включено, а Telegram не грузится — стандартный домен мог
   исчерпать дневной лимит Cloudflare (сбрасывается в 03:00 МСК) или стать
   недоступным. Укажи свой домен ([TELEGRAM.md](TELEGRAM.md)).

**Хочу вернуть Telegram без прокси.** Выключи переключатель Telegram — Fixer
подскажет, где отключить прокси в самом Telegram.

## Для разработчиков: диагностика через adb

```bash
adb logcat -s Fixer
```

Тестировать нужно **с телефона**, а не с ПК: если на ПК включён VPN, проверки
с него ничего не говорят о блокировках провайдера.

Подбор стратегии byedpi на телефоне:

```bash
adb push app/src/main/jniLibs/arm64-v8a/libbyedpi.so /data/local/tmp/bd
adb shell chmod 755 /data/local/tmp/bd
adb shell "/data/local/tmp/bd --port 1080 <аргументы> &"
adb shell curl -m 10 -so /dev/null -w '%{http_code}\n' --socks5-hostname 127.0.0.1:1080 https://www.youtube.com
```

`adb shell` не находится внутри VPN, поэтому проверки чистые. Рабочие аргументы
заносятся в `DPI_ARGS` в [FixVpnService.kt](../app/src/main/java/com/october/fixer/FixVpnService.kt).
