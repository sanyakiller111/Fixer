# Установка

## Требования

- Android 10 или новее
- Процессор ARM (почти все телефоны): arm64-v8a или armeabi-v7a
- Никакого другого VPN в это же время — Android разрешает только один

## Шаги

1. Открой страницу [Releases](../../../releases/latest) и скачай `Fixer-vX.Y.apk`.
2. Открой файл. Если телефон спросит — разреши установку из этого источника
   (Настройки → Приложения → Особый доступ → Установка неизвестных приложений).
3. Запусти **Fixer**.
4. Нажми большую круглую кнопку. Android покажет окно «Запрос на подключение» —
   нажми **OK**.
5. Статус сменится на **Подключено**. Roblox и YouTube работают.

> На Android 13+ приложение попросит разрешение на уведомления. Без него VPN
> работает, но в шторке не будет кнопки «Выключить».

## Telegram

1. На главном экране включи переключатель **Telegram**.
2. Откроется Telegram с предложением добавить прокси — нажми **Подключить**.
3. В Telegram: Настройки → Данные и память → Прокси — **выключи
   «Автопереключение прокси»**, иначе Telegram будет сам отключать Fixer.

Прокси добавляется один раз. Дальше достаточно, чтобы Fixer был включён.

Если Telegram перестал грузиться, а остальное работает — см.
[TELEGRAM.md](TELEGRAM.md), там описано, как указать свой домен.

## Плитка в шторке

Опусти шторку → карандаш (изменить) → перетащи плитку **Fixer** наверх.
Теперь включать и выключать можно, не открывая приложение.

## Обновление

Скачай новый APK и установи поверх. Настройки и прокси в Telegram сохранятся.

## Удаление

Удали приложение как обычно. В Telegram удали прокси `127.0.0.1:21441`
(Настройки → Данные и память → Прокси).
