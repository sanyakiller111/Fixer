# Telegram через Cloudflare

## Как это работает

1. Telegram подключается к локальному MTProto-прокси Fixer на `127.0.0.1:21441`.
   Ссылку `tg://proxy?...` открывает переключатель **Telegram** в приложении.
2. Fixer открывает WebSocket к `tg.<домен>/apiws?dst=<IP дата-центра>`.
3. Cloudflare Worker на этом домене соединяется с дата-центром Telegram по TCP
   на порт 443 и гоняет байты в обе стороны.

### Обход «16 КБ»-заморозки

У некоторых провайдеров соединение с Cloudflare замирает после ~16 КБ входящих
данных. DPI классифицирует соединение по **первому** запросу, а Cloudflare
маршрутизирует каждый keep-alive запрос по его собственному `Host`. Поэтому Fixer:

1. открывает обычный TCP на порт 80;
2. первым отправляет `GET /__down?bytes=1` с `Host: speed.cloudflare.com`;
3. на том же сокете делает WebSocket-upgrade с `Host: tg.<домен>.`

Если не получилось — запасной путь `wss://` на порт 443.

## Свой домен

Стандартный домен общий для всех пользователей. Если он перестал отвечать или
нужна стабильность — подними свой. Нужен домен, подключённый к Cloudflare
(бесплатный тариф подходит). Поддомены `*.workers.dev` и `*.pages.dev`
**не подходят** — у многих провайдеров они заблокированы.

### Вариант 1: через панель Cloudflare

1. Workers & Pages → Create → Worker → вставь код из
   [worker/cloudflare-worker.js](../worker/cloudflare-worker.js) → Deploy.
2. Settings → Domains & Routes → Add → Custom domain → `tg.твой-домен`.
3. SSL/TLS → Overview → режим **Flexible** (с Full будет ошибка 525).
4. В Fixer: нажми на строку **Telegram** (не на сам переключатель) → введи
   `твой-домен` (без `tg.`) → **Сохранить**.

### Вариант 2: через Wrangler

```bash
cd worker
npx wrangler login
npx wrangler deploy
```

Перед деплоем впиши свой домен в [worker/wrangler.toml](../worker/wrangler.toml).

## Ограничения

- Бесплатный тариф Workers — 100 000 запросов в сутки на аккаунт. Каждое
  соединение Telegram — один запрос.
- В Telegram должно быть выключено «Автопереключение прокси».
- Прокси локальный: работает только пока Fixer включён.
